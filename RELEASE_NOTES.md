## Winterfell Random Palette 1.0.1

Fabric-Client-Mod für Minecraft 26.3 (Java 25).

**Änderungen in 1.0.1**
- Absturz beim Öffnen der Palette durch doppelte Hintergrund-Weichzeichnung behoben.
- Eigene Hintergrunddarstellung für das Auswahlmenü.
- Gewichtete Zufallsplatzierung von ausgewählten Baublöcken aus der Hotbar.

**Bedienung**: `K` öffnet das Menü; `J` schaltet die Funktion um.

**Installation**: `winterfell-random-palette-1.0.1.jar` herunterladen, ältere Version aus dem `mods`-Ordner entfernen, neue Datei hineinlegen. Fabric API ist erforderlich. Keine Installation auf dem Server nötig.

Die `.jar.sha256`-Datei enthält den SHA-256-Hash für die Integritätsprüfung. Die Mod wurde kompiliert, ist aber noch nicht auf jedem Client-Setup getestet.

**Achtung**: Dieses Release liegt derzeit in einem privaten GitHub-Repository und ist nur für berechtigte GitHub-Konten zugänglich.
